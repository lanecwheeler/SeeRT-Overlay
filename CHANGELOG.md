# SeeRT Overlay patch notes

## 1.5.0
- Degauss: the button in Menu & App (or the CRT OSD footer) shakes the picture and swirls colour through it, like a real tube, with the coil's hum. Untick Sound to keep it quiet.
- Something magnetic is peeking in from the edge of the screen. Careful with that near the TV...
- Tooltips now draw over the cursor instead of under it.

## 1.4.0
- Patch notes: open them from Menu & App, and they show up by themselves the first time a new version runs.
- Updates ask before installing: once a new version has downloaded, you choose when to restart and install it. (Turn on Install updates without asking to have it install when you quit.)
- The first update delivered by the new auto-updater. Hello from the future!

## 1.3.0
- Updates itself: new versions download in the background and install when you restart or quit the app. Use Restart to Update to install straight away, or turn automatic updating off in Menu & App or the tray menu.

## 1.2.0
- Two new menu styles: Computer Lab and Web 1.0.
- The game-style menus hide a few secrets. Go looking.
- Option to show the settings menu in the stream window, so viewers can see it.
- A GitHub link in every menu - bug reports and ideas welcome.
- Sliders fill the menu's width and button grids are centred.
- Only one copy of the app runs at a time.

## 1.1.0
- Five new menu styles: 64 Adventure, Sword & Sorcery, Teletext (the new default), Vector Monitor and Arcade Service.
- Menu & App section: menu style, menu scale, width and height, and update settings.
- Checks GitHub for a newer version at launch.
- Screenshots of the overlay as you see it (Ctrl+Shift+PrtScn or the tray menu).
- Rebuilt CRT picture: beam scanlines, new phosphor masks and gamma, blurred glow and halation, composite colour bleed, phosphor persistence and raster bloom.
- Use your own cursor image, with an optional click-point marker.
- Quitting from the menu asks first.
- Fixes for audio loopback feedback, shake detection at any frame rate, and non-English user folder names.

## 1.0.0
- First release.
